Tạo video mới (cột trái)

Chủ đề

📝 Dùng kịch bản tự viết
Tick để dán kịch bản của bạn — phần mềm giữ nguyên văn lời đọc, chỉ lo giọng + hình + ghép.
Độ dài video
5/10/15/20 phút. Phần mềm tự chia số cảnh & số chữ phù hợp.
Quốc gia / ngôn ngữ
Quyết định ngôn ngữ kịch bản + giọng (VD us = tiếng Anh Mỹ). 17 lựa chọn.
Nhịp cắt
Nhanh 2-3s / Vừa 4-5s / Chậm 6-8s. Cắt dày giúp giữ chân người xem & né Content ID bản quyền.
Giọng đọc
Chọn engine: Edge (miễn phí), Vids/Google, ElevenLabs, ai84 (xem mục Giọng đọc).
Công thức Layer
Tỷ lệ các lớp nguyên liệu. Bấm sửa để chỉnh. (xem mục Công thức)
Tick AI video / AI ảnh
Bật/tắt dùng AI. Bỏ tick = lớp đó tự lấp bằng footage/ảnh stock — công thức % vẫn giữ nguyên.

Công thức Layer & cách đưa layer vào video thông minh

5 lớp nguyên liệu, tổng 100%. Phần mềm đưa mỗi lớp vào đúng cảnh nó hợp nhất (theo nội dung), vẫn giữ đúng tỷ lệ.

🎞️
Footage 40%Cảnh thực tế. Nguồn: Pexels, Pixabay, Vecteezy, Mixkit…
🤖
AI Video <20%Cảnh trừu tượng/khó quay. Nguồn: ai84 / Veo3.
🖼️
AI Ảnh <10%Chân dung/biểu tượng. Nguồn: Gemini (Nano Banana).
🗂️
Tư liệu cộng đồng 15%Wikimedia, Internet Archive, Openverse (CC) + thư mục clip của bạn.
🗺️
Bản đồ / Thẻ 15%Thẻ số liệu/trích dẫn/bản đồ. RVM tự tạo hoặc nối Claude thiết kế đẹp hơn.

🧠 Đưa layer vào video thông minh (tự động)

  • Cảnh có con số / % / năm / địa danh / câu trích → ưu tiên lớp Bản đồ/Thẻ (rõ ràng, chuyên nghiệp hơn footage chung chung).
  • Cảnh lịch sử / chiến tranh / xưa → ưu tiên Tư liệu cộng đồng.
  • Cảnh trừu tượng / tưởng tượng / hoành tráng → ưu tiên AI Video; chân dung/biểu tượng → AI Ảnh.
  • Cảnh thực tế còn lại → Footage, rải xen kẽ đều để không dồn cục một loại.

🗺️ Nối Claude cho lớp Bản đồ/Thẻ & đồ hoạ

Trong Cài đặt → "Bản đồ/Thẻ & đồ hoạ — nối Claude": bật Dùng Claude thiết kế + dán Claude API key. Claude sẽ thiết kế thẻ số liệu / trích dẫn / bản đồ / infographic đẹp hơn, phần mềm tự render ra hình. Không nhập key vẫn chạy bằng mẫu thẻ RVM.

🗂️ Tư liệu cộng đồng (Facebook / TikTok / nguồn khác)

Lưu ý bản quyền: Facebook/TikTok không có cổng API để tải tự do, và tải lén vi phạm điều khoản. Cách an toàn & hiệu quả: tải các clip bạn có quyền dùng về một thư mục, rồi trỏ phần mềm vào đó.

Trong Cài đặt → Thư mục tư liệu: chọn thư mục chứa clip (FB/TikTok/tự quay…). Phần mềm ưu tiên dùng cho lớp Tư liệu cộng đồng. Ngoài ra đã có sẵn nguồn cộng đồng hợp pháp: Wikimedia, Internet Archive, Openverse (giấy phép Creative Commons, không cần key).

AI Ảnh & AI Video — lấy ở đâu

Hai lớp này dùng AI tạo sinh. Bật/tắt bằng tick AI ảnh / AI video ở cột trái; nhập key trong Cài đặt.

🖼️ AI Ảnh <10% — Gemini “Nano Banana” KEY MIỄN PHÍ

  • Nguồn: Google Gemini (model ảnh gemini-2.5-flash-image = Nano Banana).
  • Lấy key: aistudio.google.com/apikey → dán vào Cài đặt → Key Gemini ảnh (dùng chung được với giọng Vids).
  • Bỏ tick AI ảnh ở cột trái = lớp này tự lấp bằng ảnh stock/thẻ (công thức % vẫn giữ).

🤖 AI Video <20% — ai84.pro (lớp Veo/Kling…) CÓ PHÍ

  • Nguồn: ai84.pro — cổng gom nhiều model AI video (Veo3, Kling, Minimax… tùy ai84).
  • Lấy key: đăng nhập ai84.pro/app → trang API → copy key → Cài đặt → ai84 API key.
  • Bấm 🔎 Khám phá API để chọn Video provider / model (VD text-to-video). Trống = tắt AI video, tự lấp bằng footage.
  • Bỏ tick AI video ở cột trái = lớp này dùng footage thay.
Google Veo/Flow (flow.google.com) chạy trên web, chưa có cổng API mở để tự động hoá — nên AI video tự động đi qua ai84 (đã gồm lớp Veo). Nếu muốn dùng Veo thủ công, bạn render trên Flow rồi thả clip vào thư mục tư liệu để phần mềm dùng.
⑤

Tab kết quả & "RÀ SOÁT VIDEO" (tự rà soát + tự sửa)

Các tab bên phải: Dự án · Kịch bản · Nhật ký · Kết quả · Trạng thái.

Sau khi ghép xong, ở tab Kết quả có khung RÀ SOÁT VIDEO: AI đã tự nhìn từng cảnh và chấm điểm (có khớp lời đọc không? mờ/tối? dính watermark/chữ/logo/timecode? khung đen? sai thời đại?). Những cảnh dưới ngưỡng được tự sửa ngay trong lúc tạo — và bộ tự sửa đã được nâng cấp để né nguồn hay dính watermark (như tư liệu Archive) và ưu tiên nguồn sạch, nét.

Bạn còn 2 nút để chủ động

🔧 Rà soát & sửa lại + ghép
Chạy lại vòng rà soát + tự sửa toàn bộ cảnh lỗi rồi ghép lại video (giữ nguyên giọng & kịch bản).
🖼️ Đổi hình cảnh
Ở từng cảnh trong danh sách — bấm để đổi sang hình khác (AI tìm hình sạch hơn, khớp hơn) rồi ghép lại.
Mỗi cảnh lỗi hiện kèm ảnh thu nhỏ + lý do + mốc thời gian (phút:giây) + cảnh/shot để bạn biết chính xác chỗ cần xem.

📊 Tỷ lệ layer THỰC TẾ

Sau khi ghép xong, phần mềm tự tính lại % thực tế của từng lớp theo thời lượng chiếm trên video (không chỉ theo số cảnh) và hiển thị bảng so sánh Công thức vs Thực tế ngay ở tab Kết quả — để bạn biết video có bám đúng tỷ lệ 40/20/10/15/15 hay không.

Lấy API key — hướng dẫn từng bước

Dán tất cả vào ⚙️ Cài đặt. Nút "Lấy"/"Lấy key" cạnh mỗi ô sẽ mở đúng trang. Ưu tiên nguồn miễn phí trước.

Pexels (footage/ảnh) MIỄN PHÍ

  1. Vào pexels.com/api/new (bấm nút Lấy cạnh ô Key Pexels).
  2. Đăng nhập / tạo tài khoản Pexels (miễn phí).
  3. Điền mục đích sử dụng → bấm Generate / Request.
  4. Copy chuỗi API Key → dán vào ô Key Pexels → Lưu.

Pixabay (footage/ảnh) MIỄN PHÍ

  1. Vào pixabay.com/api/docs (nút Lấy cạnh ô Key Pixabay).
  2. Đăng nhập Pixabay. Key hiện ngay trong trang tài liệu API (mục "Your API key").
  3. Copy → dán vào ô Key Pixabay → Lưu.

Vecteezy (footage cao cấp) 500 clip/tháng free

  1. Vào vecteezy.com/developers (nút Lấy key cạnh ô Vecteezy).
  2. Đăng nhập → vào Developer Tools → tạo một API Application.
  3. Lấy 2 giá trị: Account ID (dãy số) và Secret key.
  4. Account ID → ô Account ID Vecteezy; Secret → ô Secret key Vecteezy.
  5. Nhiều tài khoản: điền nhiều Account ID cách nhau dấu phẩy, và nhiều Secret cách nhau dấu phẩy, ghép đúng thứ tự. VD: ID 203445,203764 ↔ Secret sec1,sec2. Phần mềm xoay vòng các tài khoản để trải đều hạn 500 clip/tháng.
Gói API Vecteezy tính theo lượt tải; dùng nhiều tài khoản free để tiết kiệm. Phần mềm đã ưu tiên Pexels/Pixabay (free hẳn) trước, Vecteezy là nguồn mạnh bổ sung.

Gemini — giọng Vids + ảnh Nano Banana MIỄN PHÍ

  1. Vào aistudio.google.com/apikey (nút Lấy key cạnh ô Gemini).
  2. Đăng nhập Google → Create API key.
  3. Copy → dán vào ô Gemini API key (dùng cho cả giọng Vids & ảnh Nano Banana).

ElevenLabs (giọng cao cấp) CÓ PHÍ

  1. Vào elevenlabs.io/app/settings/api-keys (nút Lấy).
  2. Đăng nhập → Create API Key → copy.
  3. Dán vào ô ElevenLabs key. (Tùy chọn: dán Voice ID từ Voice Library.)

ai84.pro (giọng + AI video) CÓ PHÍ

  1. Đăng nhập ai84.pro/app (nút Mở ai84.pro lấy key).
  2. Vào trang API → copy API key → dán vào ô ai84 API key.
  3. Bấm 🔎 Khám phá API để xem credits + danh sách model/giọng, rồi chọn provider/voice/model bên dưới.

Claude — thiết kế Bản đồ/Thẻ & đồ hoạ CÓ PHÍ (rẻ)

  1. Vào console.anthropic.com/settings/keys (nút Lấy key trong mục Bản đồ/Thẻ).
  2. Đăng nhập → Create Key → copy.
  3. Dán vào ô Claude API key + bật Dùng Claude thiết kế. (Model mặc định claude-haiku-4-5 — nhanh & rẻ.)

9Router (bộ não viết kịch bản + AI rà soát hình)

  1. Mở phần mềm 9Router trên máy (proxy AI nội bộ, mặc định http://127.0.0.1:20128/v1).
  2. Trong Cài đặt → mục 9Router: dán API key, bấm Tải model, chọn model CÓ THỊ GIÁC (VD ag/gemini) để AI rà soát được hình.
  3. Bấm Kiểm tra kết nối thấy ✓ là xong.
Nguồn không cần key: NASA, Wikimedia, Openverse, Internet Archive, giọng Edge. Bạn có thể chạy video hoàn toàn miễn phí, rồi nâng cấp dần bằng các key trả phí khi cần chất lượng cao hơn.

Cập nhật phần mềm & bản quyền
